# 🌍 GeoQuiz

GeoQuiz is an interactive web-based geography game designed to test and improve users' global knowledge. Players can challenge themselves across multiple difficulty levels, tracking their scores as they identify countries, capitals, and flags from around the world.

## 🚀 Key Features

*   **Multiple Game Modes:** Choose between Capital City guessing, Flag Identification, and Map Location pinning.
*   **Difficulty Scaling:** Select from Easy, Medium, or Hard modes to suit different knowledge levels.
*   **Live Score Tracking:** View real-time point updates and streak counters during gameplay.
*   **Interactive Maps:** Zoom and click directly on a digital world map to submit answers.
*   **Global Leaderboard:** Save high scores to compete with classmates and friends.

## 🛠️ Tech Stack

-   **Frontend:** HTML5, CSS3, JavaScript (ES6)
-   **Mapping API:** Leaflet.js / OpenStreetMap
-   **Styling:** Tailwind CSS
-   **Backend (Optional):** Node.js with Express for leaderboard storage

## 🎮 How To Play

1.  Select your preferred **Game Mode** from the main menu.
2.  Read the prompt (e.g., *"Find the capital of Japan"*).
3.  Type your answer or click the correct location on the map.
4.  Submit before the **countdown timer** runs out!
